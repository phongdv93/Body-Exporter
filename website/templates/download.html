Hướng dẫn cài đặt Bấm để xem chi tiết
  1. Đóng SolidWorks (tránh DLL bị khóa khi cài).
  2. Giải nén ZIP → chạy Install-BodyExporter.cmd Run as administrator.
  3. Mở SolidWorks → Tools → Add-Ins → bật SolidWorks Body Exporter.
  4. Dùng shortcut Body Exporter trên Desktop để mở cửa sổ export.

Hướng dẫn sử dụng Bấm để xem chi tiết
  1. Mở file .SLDPRT trong SolidWorks.
  2. Mở Body Exporter (shortcut Desktop hoặc launcher trong thư mục cài).
  3. Plugin quét danh sách body — chỉnh tên hiển thị và trục Length / Width / Thickness.
  4. Copy All — dán vào Excel; hoặc menu Export → xuất file Excel.
  5. Lần đầu: License → trial 14 ngày (cần internet) hoặc key từ /buy.

Bấm Save trong cửa sổ export để lưu metadata vào file Part.

Export Excel & placeholder Bấm để xem chi tiết

Tạo file .xlsx mẫu của công ty, chèn placeholder vào ô cần điền — plugin thay bằng dữ liệu từng body khi export.

  1. Export ▾ → Excel template panel… — Add new… / Change… chọn file mẫu (một dòng có placeholder).
  2. Export ▾ → Fill Excel template… — chọn nơi lưu file kết quả.
  3. Body đầu tiên ghi đè dòng placeholder; các body tiếp theo chèn xuống các dòng bên dưới.
