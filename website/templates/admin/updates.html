Publish phiên bản mới

Mặc định lấy từ Chỉnh nội dung (Phiên bản + URL ZIP). Sửa nếu cần rồi bấm Publish.

Test trên máy khách

  1. Publish version cao hơn bản DLL đang cài (vd. client 0.8.1 → publish 0.8.2).
  2. Xóa %APPDATA%\SolidWorksBodyExporter\client-config-cache.json (hoặc đợi cache).
  3. Mở Body Exporter hoặc License → Check for updates.
