Thêm nhiều ảnh từ máy tính

  1. Lưu bài ít nhất 1 lần (nếu bài mới).
  2. Ở khung Upload ảnh bên dưới → Chọn file từ máy → bấm Upload.
  3. Sau upload, bấm Chèn vào HTML (VI) hoặc (EN) — ảnh được gắn vào cuối nội dung.
  4. Muốn nhiều ảnh: lặp lại bước 2–3 (mỗi lần 1 file). Có thể kéo khối <figure>…</figure> trong HTML lên đúng chỗ đoạn văn.
  5. Thay khối xanh “Chỗ gắn ảnh” (placeholder): xóa cả thẻ <div class="blog-img-placeholder">…</div> rồi chèn ảnh vào đó.
  6. Bấm Lưu bài → Xem bài để kiểm tra.

Định dạng: PNG / JPG / WEBP / GIF · tối đa 8MB / ảnh · lưu trên server tại /uploads/blog/…
